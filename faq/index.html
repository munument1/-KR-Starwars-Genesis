Genesis는 Starfield 리스킨인가?

공식 설명상 Genesis는 Starfield의 엔진과 구조를 기반으로 기존 퀘스트·장소·NPC를 크게 재작성하고 새 콘텐츠를 추가하는 방식입니다. 일부 구조가 남더라도 이야기·대사·맥락·장소·인물은 Star Wars 세계관에 맞게 바뀝니다. 아직 개발 중이라 모든 퀘스트가 변환된 상태는 아닙니다.

혼자 만든 프로젝트인가?

아닙니다. 한 명이 관리·기획·자금 지원을 크게 담당하지만, 여러 모드 제작자와 자원봉사자의 작업을 조합한 모드리스트입니다.

Xbox / Game Pass / Microsoft Store 지원?

공식 FAQ는 지원 계획이 없다고 명시합니다. Genesis는 Steam판, SFSE, Mod Organizer 2, Wabbajack과 같은 구성에 의존합니다.

Vortex Collection으로 만들 수 있나?

공식 FAQ는 지원하지 않는다고 명시합니다. 파일 덮어쓰기와 격리된 실행 환경 등 MO2 기반 구성이 필요하기 때문입니다.

스토리·광선검·포스 능력이 있나?

있습니다. 여러 Star Wars 스토리라인과 탐험 중 발견하는 광선검, 일부 기본 포스 능력이 포함됩니다.

한국어 같은 커뮤니티 번역은?

현재 공식 지원 언어는 영어지만 커뮤니티 번역은 환영한다고 안내합니다. 단, Genesis 업데이트 시 번역도 갱신하거나 내려서 사용자가 오래된 콘텐츠를 사용하지 않게 해야 합니다.

컨트롤러 / 울트라와이드

컨트롤러는 거의 전체 지원, 울트라와이드는 제한적 지원입니다. 일부 HUD 요소는 Genesis 버전 대신 바닐라 형태로 보일 수 있습니다.

모드를 더 추가하거나 LOOT를 써도 되나?

공식 가이드는 권장하지 않습니다. Genesis 내부 모드가 별도 패치·수정을 거쳤기 때문에 작은 변경도 핵심 기능을 깨뜨릴 수 있으며, 수정된 설치는 공식 지원 대상에서 제외됩니다.

기술 지원 목적이라면 FAQ보다 Self Help와 문제 해결 목차를 먼저 사용하는 편이 빠릅니다.
