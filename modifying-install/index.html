MODIFYING INSTALL

Genesis에 추가 모드 설치

원문 확인: 2026-10-07 · 공식 원문 ↗

수정 설치: Genesis에 모드를 하나라도 추가하면 해당 설치와 세이브는 'Modified'로 취급됩니다. 나중에 그 모드를 지워도 세이브가 다시 순정 Genesis 상태가 되는 것은 아닙니다.

공식 지원 범위도 줄어듭니다. 일반 설치 문제 외에는 Modified-Install 전용 채널을 사용해야 하며, 추가 모드가 원인일 가능성이 있는 버그는 일반 지원 대상이 아닙니다.

추가 모드 세이브를 장기적으로 관리하려면 Modified Save 관리도 함께 확인하세요.

업데이트 때 추가 모드가 지워지는 문제

Wabbajack 업데이트는 Genesis 원본 목록에 없는 추가 모드를 삭제할 수 있습니다. 유지하고 싶은 추가 모드는 MO2에서 이름 앞에 [NoDelete] 를 붙이는 방법을 공식 가이드가 안내합니다. 공백까지 포함한 접두어 형식을 정확히 지켜야 합니다.

예시 형식: [NoDelete] My Additional Mod

다만 [NoDelete]가 업데이트 호환성을 보장하는 것은 아닙니다. Genesis가 갱신될 때 추가 모드와 새 버전이 충돌하면 세이브 손상이나 크래시가 생길 수 있습니다.

특히 피해야 할 것

  • Genesis 내부 모드를 이유 없이 최신 버전으로 교체하기.
  • 2024-08-20 이전 제작/업데이트된 HUD 모드를 추가하기.
  • LOOT를 Genesis 모드리스트에 실행하기. 원문은 로드 순서가 깨진다고 명시합니다.
  • 대규모 게임플레이/NPC/함선 모드를 한꺼번에 추가한 뒤 일반 Help/Bug Report 채널에서 문제를 신고하기.

지원 가능한 사례와 어려운 사례

Wabbajack/MO2 설치 자체의 문제나, 추가한 모드와 명백히 무관한 음성·환경 문제는 여전히 도움을 받을 수 있습니다. 반대로 새로 설치한 방어구가 깨졌거나 수십 개 게임플레이 모드 때문에 크래시하는 경우는 Modified Install 문제로 봅니다.

권장: 추가 모드를 쓰려면 한 번에 하나씩 넣고, 수동 저장 백업과 변경 기록을 남기세요. Genesis 업데이트 전에 추가 모드 호환 여부를 다시 확인하는 것이 좋습니다.
