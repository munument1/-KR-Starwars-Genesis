## GitHub Pages 설정

저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**로 설정하면 루트의 `index.html`을 배포할 수 있습니다. 공개 완료 여부는 GitHub Pages 배포 상태를 통해 확인하세요.

## 검색엔진

HTML에 `<meta name="robots" content="noindex,nofollow">`를 삽입했습니다. 저장소 안의 `robots.txt`는 GitHub 프로젝트 사이트에서 **도메인 최상위 robots.txt가 아니므로 차단 효력을 보장하지 않습니다**. 게시 자체를 비공개로 만들지는 않습니다.
