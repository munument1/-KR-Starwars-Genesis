저사양 PC 설정

원문 확인: 2026-10-07 · 공식 원문 ↗

Genesis 최소 사양에 가까운 PC에서 화질을 희생해 성능을 확보하는 선택적 설정입니다. 먼저 일반 성능 가이드를 적용한 뒤 진행하세요.

필수: 원문은 80GB page file을 가장 먼저 강조합니다.
  1. MO2 정렬 상태 확인
    왼쪽 모드 목록이 Priority 기준으로 정렬되어 있고 0이 위쪽인지 먼저 확인합니다. 알파벳순으로 정렬된 상태에서 카테고리 단위 비활성화를 하면 엉뚱한 모드를 대량으로 끌 수 있습니다.
  2. 얼굴 텍스처 비활성화
    Visuals → Face Textures 아래의 모드를 모두 끕니다.
  3. 조명 모드 비활성화
    Visuals → Lighting 아래의 모드를 모두 끕니다.
  4. Starfield Performance BOOST
    원문에서 연결하는 Nexus 모드를 Manual Download로 받은 뒤 INI 파일을 Starfield 게임 폴더에 넣습니다.

텍스처 다운스케일

원문은 최신 텍스처 다운스케일러로 Reduced Texture Detail을 안내합니다. ZIP 그대로 Genesis의 Downloads 폴더에 넣고 MO2에서 설치합니다.

이 가이드는 화질 저하를 전제로 합니다. 원본 모드 목록을 임의로 광범위하게 끄기 전에 정확한 카테고리와 Priority 정렬을 반드시 확인하세요.
