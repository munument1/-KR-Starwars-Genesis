페이지 파일 설정 순서

  • 원문은 특히 RAM 16GB 이하 또는 VRAM 8GB 미만에서 이 설정을 안내합니다. 가장 빠른 SSD에 80GB 공간을 확보합니다.
  • Win+R → sysdm.cpl → 고급 → 성능의 설정 → 고급 → 가상 메모리 변경으로 이동합니다.
  • 모든 드라이브의 페이징 파일 크기 자동 관리를 해제하고 SSD를 선택합니다. 사용자 지정 크기의 처음 크기와 최대 크기를 모두 80000MB로 입력합니다.
  • 설정 → 확인을 누르고 컴퓨터를 재부팅합니다. 페이지 파일은 지정한 디스크 공간을 사용합니다.
