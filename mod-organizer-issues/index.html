Mod Organizer 2 문제 해결

원문 확인: 2026-10-07 · 공식 원문 ↗

MO2가 열리지 않거나 Genesis 실행이 실패할 때, 모드리스트 자체보다 Windows 런타임·보안·파일 권한·저장장치 환경을 먼저 배제하는 것이 공식 가이드의 방향입니다.

일반 점검 순서

  1. Visual C++
    VC++ 런타임이 최신인지 확인합니다. 공식 페이지는 All-in-One 설치와 Microsoft x64 패키지 복구를 함께 권장합니다. Microsoft VC++ x64 ↗
  2. .NET Framework
    최신 .NET Framework 설치 상태를 확인합니다.
  3. Windows 보안 예외
    차단 기록이 실제로 있다면 steamapps\common\Starfield, Star Wars Genesis\Game, Documents\My Games\Starfield를 대상으로 제한적인 예외를 검토합니다.
  4. Controlled Folder Access
    Documents 기록을 막고 있다면 Starfield/MO2에 필요한 접근만 허용합니다.
  5. 다운로드 파일 차단 해제
    Genesis 설치 폴더에서 PowerShell의 dir -Recurse | Unblock-File을 사용하는 방법이 원문에 있습니다. 외부 다운로드 차단이 의심될 때만 사용하세요.
  6. 서드파티 백신 확인
    PowerShell에서 다음 명령으로 Windows Security가 인식하는 백신 목록을 볼 수 있습니다.
    Get-CimInstance -Namespace root/SecurityCenter2 -ClassName AntivirusProduct |
Select-Object displayName, productState
    Defender 외 제품이 있으면 충돌 프로그램 안내와 해당 제품의 격리 기록을 확인합니다.
  7. 충돌 앱 종료
    RTSS·오버레이·오디오·튜닝 도구 등이 원인인지 확인합니다.

Documents 경로 문제

Windows 사용자 Documents 경로에 비라틴 특수문자가 포함된 환경에서 MO2/Starfield 문제가 발생한 사례가 공식 가이드에 있습니다. 레지스트리를 직접 편집하기 전에는 현재 Documents 위치와 OneDrive 리디렉션 상태를 먼저 확인하고 백업하세요.

그래도 안 될 때 볼 환경 문제

  • Debloat Windows: 임의의 Windows 경량화 스크립트로 필수 구성요소를 제거한 경우.
  • 드라이브 손상: 특히 SFSE Plugin Loader 오류와 함께 나타나는 경우 디스크 상태 점검.
  • AVX2: BIOS에서 비활성화했거나 매우 오래된 CPU일 때.
  • OS/파일 구조 문제: 다른 프로그램까지 비정상적이면 Windows 자체 문제 가능성.

특정 오류

Side-by-Side Configuration Error

손상되거나 오래된 VC++ 런타임과 관련될 수 있습니다. VC++ 복구 후 StarWarsGenesisSetup.exe의 Repair를 진행합니다.

Baka Hold to Sprint Disabled

Genesis가 설치된 드라이브에서 VC++ x64 구성요소를 다시 확인합니다.

RealTimeFormPatcher / Unsupported Address Library Format

Microsoft VC++ x64 재설치를 우선 확인합니다.

Plugins 순서가 섞임

MO2의 Plugins 탭 상단에 있는 백업 복원 버튼으로 Genesis 기본 플러그인 순서를 복원합니다.

보안/권한 주의: 원본에는 관리자 실행, Everyone 전체 권한, Controlled Folder Access 해제 같은 강한 조치도 포함됩니다. 이 한국어판은 먼저 차단 로그를 확인하고 필요한 폴더·프로세스에만 최소 범위 예외를 적용하도록 권장합니다.
