Wabbajack 설치 오류

원문 확인: 2026-10-07 · 공식 원문 ↗

설치 실패 화면보다 로그 바로 위의 오류 문구가 중요합니다. 같은 경로로 재실행하면 이미 받은 파일을 재사용하며 이어받을 수 있습니다.

다운로드 관련

Reached API Limit

원문 기준 Nexus API 한도는 24시간 10,000회이며 한도에 도달한 뒤에는 시간당 500회가 추가됩니다. Genesis 자체가 보통 이 한도를 소모할 정도로 무거운 목록은 아니므로, 반복 도달한다면 불안정한 인터넷 연결을 먼저 의심합니다. 가능하면 유선 연결 또는 Wabbajack CDN 변경을 시험합니다.

Unable to Source File

우선 Retry를 누릅니다.

Unable to Download / OAuth Token Errors

  • Wabbajack 안에서 Nexus 로그인 누락.
  • 로그인 실패 반복으로 일시적인 IP 제한.
  • VPN 때문에 Nexus 다운로드 차단.
  • 지역/네트워크에서 Nexus 또는 GitHub 접근 제한.
  • 대용량 파일을 끝까지 받지 못하는 불안정한 회선.

Stuck Download

  1. 설치기를 닫습니다.
  2. 이전과 정확히 같은 설치 위치로 다시 시작합니다.
  3. 같은 파일에서 계속 멈추면 Downloads 폴더에서 해당 모드 압축파일만 삭제합니다.
  4. Wabbajack을 닫고 %localappdata%의 Wabbajack 캐시 폴더를 삭제합니다.
  5. Wabbajack을 다시 열어 설치를 재개합니다.

게임·파일 경로

Can't Find Game Starfield

  • Steam판 Starfield인지 확인.
  • Steam이 두 군데 설치되어 Wabbajack이 잘못된 라이브러리를 보고 있지 않은지 확인.

Unable to hash ...

다운로드 파일 손상 오류입니다. 원문은 Genesis Downloads 폴더를 새로 만들어 다시 설치하는 방법을 안내합니다. 전체 폴더 삭제 전 필요한 파일을 다시 받을 수 있는지 확인하세요.

Could not find part of the path “TEMP_BSA_FILES”

  1. Wabbajack 종료.
  2. Star Wars Genesis\Game\TEMP_BSA_FILES가 있으면 폴더 자체가 아니라 내부 내용만 비웁니다.
  3. Wabbajack을 다시 실행해 같은 설치를 재개합니다.

Data_Starfield-Textures0X.BA2 다운로드 실패

Starfield 게임 파일 손상으로 보는 오류입니다. 로그에서 지목한 파일을 게임 폴더에서 제거한 뒤 Steam 복구를 진행하고 Wabbajack을 재개합니다. 다만 Bethesda가 새 게임 버전을 막 배포한 시점에는 지원 버전을 먼저 확인하세요.

Windows 환경

Access Denied

서드파티 백신 또는 Windows 보안이 파일 접근을 막는 경우가 많습니다. 차단 기록을 먼저 확인하고, 필요한 경우 Starfield, Star Wars Genesis\Game, Documents\My Games\Starfield만 제한적으로 예외 처리합니다.

“You can’t run Wabbajack as Admin”

기본 Windows보다 강화된 UAC/권한 정책 때문에 발생할 수 있습니다. UAC를 무조건 낮추기보다 Wabbajack을 관리자 권한으로 강제 실행하도록 설정한 항목이 있는지 먼저 확인하세요.

Disk I/O Error

SSD 여유 공간이 부족하거나 AMD StoreMI 같은 저장장치 가속/관리 프로그램과 충돌하는지 확인합니다.

Nexus 로그인 창이 흰색

Microsoft Edge/WebView2 구성요소 누락과 관련될 수 있습니다. Edge와 WebView2 Runtime ↗을 복구합니다.

주의: 백신 제거, UAC 완전 해제, Windows 핵심 구성요소 삭제/재설치 같은 강한 조치는 마지막 단계로 두세요. 먼저 오류 로그와 차단 기록을 확인하는 편이 안전합니다.

Wabbajack 설치 오류 보완

  • Steam이 두 위치에 설치되어 있으면 Wabbajack이 다른 라이브러리를 참조할 수 있습니다. 원문은 중복 설치 정리를 제안하므로 먼저 실제 게임 경로를 확인하세요.
  • 복제품 제한: 불법 복제판 스타필드는 Wabbajack 내부 안전장치에 의해 지원되지 않습니다.
  • BSA 임시 폴더 오류 유의사항: 서드파티 자동 클릭 등 외부 Wabbajack 매크로 프로그램을 사용하면 TEMP_BSA_FILES 추출 오류가 유발될 수 있으므로 중단해야 합니다.
  • 관리자 권한 오류에 대해 원문은 UAC 설정 변경도 제안합니다. 먼저 Wabbajack의 관리자 권한 강제 실행 설정을 확인하고, 필요한 경우에만 원문 절차를 검토하세요.
