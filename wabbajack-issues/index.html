Wabbajack 설치 오류

원문 확인: 2026-10-07 · 공식 원문 ↗

설치가 실패하면 Wabbajack 로그의 마지막 오류 메시지를 먼저 확인하세요. 아래는 원문에 있는 주요 오류별 확인 사항입니다.

다운로드 관련

Reached API Limit

Nexus 요청 한도에 도달했다면 네트워크 안정성을 점검하세요. 가능하면 유선 연결이나 Wabbajack의 CDN 변경을 시도하고, 제한이 풀린 후 재개합니다.

Unable to Source File

우선 Retry를 누릅니다.

Unable to Download / OAuth Token Errors

Wabbajack 안의 Nexus 로그인 여부, VPN, 지역별 접속 차단, 불안정한 연결을 차례로 확인합니다.

Stuck Download

설치기를 닫았다가 이전과 같은 경로를 지정해 다시 시작합니다. 반복된다면 문제 파일을 확인한 뒤 캐시 정리 절차를 원문에서 확인하세요.

파일·환경 관련

Can't Find Game Starfield

Steam판인지 확인하고 중복된 Steam 설치로 경로 인식이 꼬이지 않았는지 점검합니다.

Unable to hash ...

손상된 내려받기 파일일 수 있습니다. 해당 문제 파일을 교체하거나 원문의 다운로드 폴더 재구성 절차를 따릅니다.

TEMP_BSA_FILES 경로 오류

Wabbajack을 닫은 뒤 Star Wars Genesis\Game\TEMP_BSA_FILES의 임시 파일을 점검하고 설치를 다시 시작합니다.

Access Denied

보안 프로그램의 차단 기록을 확인합니다. 예외가 필요하다면 원문에 지정된 게임·모드 폴더만 대상으로 설정하세요.

Textures BA2 다운로드 실패

문제가 된 Starfield 게임 파일을 Steam의 파일 무결성 검사로 복구한 뒤 다시 시도합니다.

Disk I/O

SSD 저장 공간을 확보하고 AMD StoreMI 같은 저장장치 관리 프로그램과 충돌하는지 확인합니다.

Nexus 로그인 창이 흰색

Microsoft Edge와 WebView2 Runtime 설치 상태를 점검합니다. WebView2 공식 안내 ↗

주의: 관리자 권한이나 백신을 무조건 끄기보다 먼저 오류 기록과 제한적인 예외 설정을 확인하는 편이 안전합니다. 오류가 남으면 공식 해결 페이지의 세부 조건을 따르세요.

이 페이지는 비공식 한국어 안내입니다. 실제 설치 전에 원문의 최신 지침을 확인하세요.
