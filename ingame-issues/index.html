게임 내 오류

원문 확인: 2026-10-07 · 공식 원문 ↗

Genesis가 정상 실행된 뒤 발생하는 화면·저장·함선·퀘스트 문제입니다. 크래시나 무한 로딩은 성능/안정성 안내 또는 Self Help를 먼저 확인하세요.

화면·저장·파일

해상도가 1280×720으로 고정됨

  • Borderless Fullscreen을 껐다 다시 켭니다.
  • Windows 디스플레이 배율을 100%로 시험합니다.

저장 실패

  1. Steam Cloud Save를 끕니다.
  2. Documents\My Games\Starfield\Saves 경로가 실제로 존재하는지 확인합니다.
  3. Windows 보안이 Starfield의 Documents 접근을 막는지 확인합니다.
  4. OneDrive를 사용한다면 실제 Documents 위치가 OneDrive 아래인지 확인합니다.
  5. 마지막 수단으로 OneDrive 동기화를 잠시 중지해 비교합니다.

설정이 재시작 후 초기화됨

Windows Defender 또는 다른 보안 프로그램이 Starfield의 Documents 쓰기를 막는 경우가 많습니다. 보호 기록에서 Starfield.exe 차단 여부를 확인합니다.

로딩이 몇 분씩 걸림

공식 가이드는 외장 SSD, SATA SSD, HDD를 Genesis 최소 요구보다 느린 환경으로 봅니다. 디스크 상태와 실제 읽기/쓰기 속도를 확인하고, NVMe SSD는 대략 4,000MB/s 이상의 읽기/쓰기를 기준 예시로 듭니다.

광선검이 흰색

Documents 설정 문제일 가능성이 큽니다. Documents 수동 설치와 Windows 보안 차단을 확인합니다.

함선·지역

우주선에 들어갈 수 없음 / Dock 표시가 없음

먼저 저장 후 게임을 재시작합니다. 반복 재현된다면 함선 관련 SFSE 플러그인이 VC++ 런타임 문제로 로드되지 않는지 확인합니다.

Geonosis 바닥 누락

세이브 자체보다 게임/모드 파일 손상 가능성을 먼저 봅니다. 추가 모드, 비표준 Wabbajack 포크 사용 여부를 확인하고, 해당되지 않으면 Starfield clean reinstall 또는 Genesis Repair를 고려합니다.

모든 것이 투명/회색/보라색

원본은 Creation Kit 작업 중 Materials 폴더 이름을 잘못 남긴 추가 모드가 이런 증상을 만들 수 있다고 설명합니다. 추가 모드를 사용했다면 해당 모드부터 비활성화해 비교하세요.

캐릭터·퀘스트

제트팩 화염이 이상하거나 제트팩이 떠 있음

콘솔에서 showlooksmenu player 2를 실행해 캐릭터 편집 화면을 잠깐 열었다 닫습니다.

퀘스트 NPC가 계속 공격함

  1. 침대/의자 등에서 48시간 대기합니다.
  2. 잠입 미션이 막힌 경우에 한해 tdetect로 감지를 잠시 끄고 다음 목표까지 이동한 뒤 다시 입력해 켭니다.

행성/대사가 바닐라 그대로

Steam에서 Starfield 언어가 English인지 확인합니다. Genesis는 아직 WIP라 일부 바닐라 음성/내용이 남아 있을 수 있습니다.

문을 열 수 없음

바닐라 Bethesda 버그 사례가 있으므로 게임 재시작 또는 세이브 재로드를 먼저 합니다.

Alternate Start에서 함선이 없음

함선 기술자에게 말을 걸고 Ship Builder를 잠깐 열어보거나 다른 위치로 빠른 이동해 봅니다.

빠른 이동 불가

  1. 콘솔에 DumpInputEnableLayers 입력.
  2. 출력된 Layer 중 Fast Travel이 표시된 번호를 찾습니다.
  3. ResetInputEnableLayer NUMBER에서 NUMBER를 해당 번호로 바꿔 실행합니다.
콘솔 명령을 사용하기 전에 별도 수동 저장을 남기세요. 추가 모드를 사용 중이라면 Modified Save 문제인지도 확인해야 합니다.

추가 문제 해결

  • 저장이 안 되면 Documents\My Games\Starfield\Saves 폴더의 존재와 쓰기 권한, Windows 보안의 폴더 접근 차단 기록을 확인합니다.
  • 흰색 광선검 문제에 대해 원문은 Genesis·Starfield·Starfield Documents 폴더의 접근 권한 점검을 제안하며, Everyone에 모든 권한을 주는 절차도 포함합니다. 먼저 현재 사용자에게 필요한 읽기·쓰기 권한이 있는지 확인하세요.
  • 함선 도킹 불가 문제 시 StarWarsGenesisSetup.exe가 설치하는 VC++ 런타임이 백신 등에 의해 차단되었을 수 있으며 수동 설치가 필요할 수 있습니다.
