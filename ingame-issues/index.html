게임 내 오류

원문 확인: 2026-10-07 · 공식 원문 ↗

게임이 실행된 뒤 발생하는 문제를 다룹니다. 크래시·무한 로딩은 공식 성능 문제 안내를 우선 확인하세요.

화면·파일 문제

해상도가 1280×720으로 고정됨

Borderless Fullscreen을 껐다 켜고 Windows 디스플레이 배율 100%를 시험합니다.

저장 실패

Steam Cloud 저장을 끄고 Documents\My Games\Starfield\Saves 존재 여부, Windows 보안의 폴더 차단, OneDrive 문서 경로를 확인합니다.

설정이 재시작 후 초기화됨

Windows 보안이 게임의 Documents 기록을 막았는지 보호 기록을 확인합니다.

로딩 시간이 지나치게 김

외장 드라이브·HDD·느린 SSD에 설치했는지 확인하고 디스크 상태와 속도를 점검합니다.

광선검이 흰색으로 보임

Documents 설정과 파일 접근 권한 문제일 수 있어 원문의 Manual Documents Install을 확인합니다.

게임플레이 문제

우주선 진입·도킹 실패

저장 후 재시작하고, 반복된다면 Visual C++ 관련 구성요소를 점검합니다.

지오노시스의 바닥이 사라짐

게임·모드 파일 손상 여부와 추가 모드를 확인한 뒤 Steam 복구 또는 Genesis Repair를 고려합니다.

제트팩 화염·위치가 이상함

콘솔에서 showlooksmenu player 2로 외형 편집 화면을 잠깐 열었다 닫습니다.

퀘스트 NPC가 공격적임

48시간 대기 후 재확인하세요. 잠입 퀘스트가 막힌 경우 원문에 tdetect 콘솔 사용 안내가 있습니다.

행성·대사가 바닐라와 같음

Steam에서 Starfield 언어가 English로 지정돼 있는지 확인합니다.

문이 열리지 않음 / 대체 시작 우주선 누락

게임 재시작·세이브 다시 불러오기, 또는 함선 기술자에게 말을 걸어 빌드 화면 진입을 시험합니다.

빠른 이동 불가

원문에는 DumpInputEnableLayers로 레이어를 확인한 뒤 ResetInputEnableLayer NUMBER를 사용하는 방법이 있습니다. 번호는 출력 결과를 보고 선택해야 합니다.

콘솔 명령은 세이브를 백업한 다음 사용하세요. 실행 결과가 예상과 다르면 중단하고 원문 안내를 확인하세요.

비공식 한국어 안내입니다. 버전이 바뀌면 원문을 먼저 확인하세요.
