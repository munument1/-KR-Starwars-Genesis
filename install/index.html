Star Wars Genesis 신규 설치

원문 기준: Genesis 8.8.3 설치 페이지 · 확인일 2026-10-07 · 공식 원문 ↗

중요: 아래 조건이 맞지 않으면 설치가 실패하거나 세이브가 손상될 수 있습니다. 세부 단계는 현재 번역 진행 중이므로, 실제 설치 직전에는 반드시 공식 원문도 함께 확인하세요.

필수 조건

  • Steam판 정품 Starfield — Game Pass/Microsoft Store판은 지원하지 않음
  • Shattered Space DLC
  • 공식 설치 페이지가 지정하는 Starfield 버전
  • Genesis 설치 후 시작한 새 세이브
  • 게임 언어: English
  • Creation Store/Vortex를 통한 기존 모드가 남아 있지 않을 것
  • Starfield와 Genesis 모두 내부 NVMe SSD에 설치
공식 설치 페이지는 Steam Deck/ROG Ally를 호환 대상으로 보지 않습니다. 또한 VRAM이 낮을 경우 메뉴 지연 등 성능 문제가 발생할 수 있다고 안내합니다.

설치 전에

  • Windows 페이지 파일을 공식 권장값에 맞춰 충분히 확보합니다.
  • 설치를 방해하는 서드파티 백신·VPN·오버레이 프로그램이 있는지 확인합니다.
  • Starfield와 Genesis를 같은 SSD 드라이브에 둡니다.
  • Starfield 자동 업데이트를 끕니다.
  • 과거 Starfield 모드 설치 흔적이 있다면 공식 초기화 안내를 먼저 따릅니다.

설치 흐름

  1. Starfield를 Steam에서 한 번 실행
    게임을 최소 한 번 실행한 뒤 종료합니다.
  2. Genesis 설치기 실행
    공식 사이트에서 제공하는 StarWarsGenesisSetup.exe를 사용합니다. 다운로드 링크는 변할 수 있으므로 이 한국어판에 직접 복제하지 않고 원문 링크를 기준으로 합니다.
  3. 설치 위치 지정
    공식 가이드가 지정한 Star Wars Genesis 폴더 구조와 드라이브 조건을 그대로 따릅니다.
  4. Wabbajack 설치 위치 확인
    Wabbajack의 Installation Location은 공식 가이드가 지정하는 Star Wars Genesis\Game 경로를 정확히 사용합니다.
  5. 설치 진행
    NexusMods 로그인 후 Wabbajack 설치를 진행합니다. 중단되더라도 같은 위치에서 다시 실행하면 이어받을 수 있습니다.
  6. 설치 후 문서 설정
    공식 가이드가 안내하는 GENESIS_DOCUMENTS.bat 단계와 Mod Organizer 2 실행 단계를 순서대로 진행합니다.

첫 실행

Mod Organizer 2에서 Genesis 실행 항목을 선택하여 게임을 시작합니다. 새 게임을 시작한 뒤 캐릭터 생성과 초기 로딩이 끝나면 수동 저장하고, 게임을 완전히 재시작한 뒤 해당 저장을 불러오는 것이 공식 가이드의 흐름입니다.

번역 진행 상태: 이 페이지는 핵심 설치 흐름을 먼저 한국어화한 1차본입니다. 이미지별 설명, 문제 해결 분기, 그래픽 설정, 난이도, 백업 안내는 다음 작업에서 원문 구조에 맞춰 추가합니다.
