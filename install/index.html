Star Wars Genesis 신규 설치

원문: Genesis 8.8.3 Installation Guide · 확인일 2026-10-07 · 공식 원문 ↗

중요: Genesis는 아직 완성형 모드리스트가 아니며 계속 업데이트됩니다. 설치 직전에는 반드시 공식 페이지의 최신 Starfield/Genesis 버전을 다시 확인하세요.
한국어 패치를 적용하려면Genesis 설치를 마친 뒤, 아래 한국어 패치 적용 방법을 따라 진행하세요. Genesis 8.8.32용 v0.1.0 다운로드·설치·복원 안내.
Steam 키 안내할인 키 구매 시 Game Pass/Microsoft 버전 주의제거 방법Portable MO2 구조와 삭제 방법

필수 조건

  • Steam판 정품 Starfield — Game Pass/Microsoft Store판은 지원하지 않습니다.
  • Shattered Space 확장팩.
  • Starfield 1.16.244 — 원문 8.8.3 기준. 최신 여부는 설치 직전 다시 확인.
  • Genesis 설치 후 새로 시작한 세이브.
  • 게임 언어를 English로 설정. 일반 Starfield용 Nexus 번역 모드를 별도로 추가하지 않습니다. 이 사이트에서 배포하는 Genesis 8.8.32 전용 한국어 패치는 아래 안내를 따르세요.
  • Creation Store/Vortex를 통한 기존 모드를 제거합니다. Bethesda Creation도 포함됩니다.
  • Starfield와 Genesis 모두 내장 NVMe SSD에 설치합니다.

AMD GPU 사용자는 원문에서 Starfield와 치명적 문제가 있다고 경고한 특정 드라이버 버전(26.8.1)을 피하고 최신 드라이버로 갱신하도록 안내합니다.

Wabbajack이란? Genesis 제작자의 Mod Organizer 2 구성과 수백 개 모드의 설치를 자동화하는 모드리스트 설치 도구입니다. Nexus Premium이 없으면 일부 다운로드를 사용자가 직접 눌러야 하지만, 이후 구성은 자동으로 진행됩니다.

설치 전 준비

  • 과거 Starfield를 모딩한 적이 있다면, 특히 Vortex나 Creation Store를 사용했다면 기존 모드 흔적 정리부터 진행합니다.
  • Windows page file을 최소 80GB로 늘립니다.
  • 서드파티 백신이 설치를 막는지 확인합니다. BitDefender/McAfee/Norton 사용자는 공식 별도 안내를 확인하세요.
  • 오버레이·성능·오디오 프로그램은 충돌 프로그램 안내와 대조합니다.
  • VPN이 다운로드를 막을 수 있으므로 설치 중 문제가 생기면 끕니다.
  • Starfield와 Genesis를 같은 SSD 드라이브에 둡니다.
  • Starfield 자동 업데이트를 끕니다.

Wabbajack 설치

  1. Steam에서 Starfield를 한 번 실행
    아무 작업보다 먼저 Steam을 통해 Starfield를 최소 한 번 실행한 뒤 종료합니다.
  2. Genesis 설치기 실행
    공식 설치 페이지에서 StarWarsGenesisSetup.exe를 Standard Download로 내려받아 실행합니다.
  3. Genesis 설치 위치 지정
    드라이브 루트의 Star Wars Genesis 폴더 이름과 위치를 유지합니다. 드라이브 문자는 Starfield가 설치된 드라이브와 맞춥니다.
  4. Wabbajack Installation Location 지정
    설치 위치는 반드시 Star Wars Genesis\Game입니다. Star Wars Genesis까지만 선택하면 안 됩니다.
  5. 설치 시작
    Nexus Mods 로그인을 완료한 뒤 설치를 시작합니다. 중간에 닫아도 같은 설치 위치를 지정해 다시 실행하면 기존 다운로드를 재사용하며 이어갈 수 있습니다. 반복되는 다운로드 오류는 Wabbajack 오류 안내를 확인하세요.
  6. GENESIS_DOCUMENTS.bat 실행
    설치 완료 후 Star Wars Genesis\Game 폴더에서 GENESIS_DOCUMENTS.bat를 실행합니다. 질문을 읽고 답하세요. 원본 BAT의 최고 그래픽 설정 질문에서 무조건 Y를 선택하지 마세요. 한국어 패치를 적용하면 이 BAT도 한국어 안내로 바뀌며, 최고 그래픽은 정확히 MAX를 입력해야 선택됩니다. 파일이 없으면 설치 후 파일 누락 복구, 실행 오류가 나면 Documents 수동 설치를 확인하세요.

한국어 패치 적용 방법

커뮤니티 추가 안내 · Genesis 8.8.32용 한국어 패처 v0.1.0 · 확인일 2026-10-07

Genesis 설치를 완료한 뒤 적용합니다. 플러그인과 Strings 번역, 메뉴·설정 UI, Pretendard 한글 폰트, 원형 HUD 행성 이름의 간격 보정, 추가 DLC Strings 및 한국어 BAT 안내를 포함합니다. 게임 언어는 계속 English로 유지하세요.

한국어 패처 v0.1.0 다운로드 ↗릴리즈의 GenesisKRPatcher-v0.1.0.zip을 내려받으세요. 패처 저장소·문제 신고 ↗전체 사용 안내와 확인 범위. 오역·글자 잘림은 Issues에 스크린샷과 위치를 알려주세요.
  1. 게임 완전히 종료
    Starfield를 종료합니다. 화면이 없어도 작업 관리자에 Starfield.exe가 남아 있으면 종료된 상태가 아닙니다.
  2. ZIP 압축 해제 후 EXE 실행
    GenesisKRPatcher-v0.1.0.zip을 풀고 GenesisKRPatcher.exe를 실행합니다. Python, Java, xTranslator 또는 API 키를 별도로 준비할 필요가 없습니다.
  3. Genesis의 Game 폴더 선택
    mods, profiles, ModOrganizer.ini가 들어 있는 폴더를 선택합니다. 예: D:\Star Wars Genesis\Game. 드라이브 문자는 본인의 설치 위치에 맞춥니다. Steam의 Starfield 설치 폴더를 선택하지 마세요.
  4. 검사하고 패치 생성
    패처에서 검사하고 패치 생성을 누르고 완료될 때까지 기다립니다. 이 단계는 번역 파일을 준비하며 게임 파일을 변경하지 않습니다.
  5. 백업 후 적용
    준비 완료 후 백업 후 적용을 눌러 설치합니다. 패치 생성만 하고 창을 닫으면 번역이 적용되지 않습니다. 기존 시험판 적용자도 같은 절차를 사용하면 되며, 이미 적용된 파일은 건너뜁니다.
  6. MO2에서 다시 실행
    Star Wars Genesis Compiler 프로필과 기존 Genesis/SFSE 실행 항목을 사용합니다. 처음 화면이 뜨기까지 몇 분 걸릴 수 있으므로 중복 실행하지 말고 기다리세요. 메뉴의 새 게임·불러오기·설정이 한글로 표시되는지 확인합니다.
적용 위치: 제네시스의 mods 폴더와 Game 폴더의 GENESIS_DOCUMENTS.bat에 적용합니다. Steam 본편 Starfield\Data는 수정하지 않습니다. Genesis가 스타워즈식으로 바꾼 영문을 기준으로 번역합니다.

원본으로 되돌리기

게임을 완전히 종료한 뒤 패처의 백업 복원을 누르고, 선택한 Game 폴더의 .genesis-kr-backups\작업번호\journal.json을 선택합니다. 여러 번 나누어 적용한 경우, 모두 되돌리려면 최근 백업부터 역순으로 복원하세요. 백업 폴더는 복원이 필요할 수 있으므로 보관합니다.

적용이 안 될 때

  • 메뉴가 여전히 영어: 패치 생성뿐 아니라 백업 후 적용까지 완료했는지 확인하고 게임을 완전히 종료한 뒤 다시 실행합니다.
  • 버전·원본 파일·모드 우선순위 오류: v0.1.0은 확인된 Genesis 8.8.32 구성용입니다. 오류를 무시하고 수동으로 덮어쓰지 말고 패처의 오류 문구를 Issues에 알려주세요.
  • Genesis 업데이트 후: 기존 패처가 새 버전과 호환된다고 가정하지 마세요. 새 버전에 대응하는 릴리즈 안내를 확인합니다.

메뉴 번역·한글 폰트·원형 HUD 행성 이름은 실제 게임에서 확인했습니다. 전체 퀘스트 및 대사의 플레이 검증과 기존 번역 전체의 사람 교열은 완료되지 않았습니다. 이 패치는 커뮤니티 배포물이며 공식 Genesis 지원 번역으로 등록됐다는 의미는 아닙니다.

설치 후 실행

  1. Mod Organizer 2 실행
    Star Wars Genesis\Game\ModOrganizer.exe를 실행합니다. NXM 링크 연결 여부를 묻는 창이 나오면 Yes를 선택합니다. 실행이 안 되면 MO2 문제 해결로 이동하세요.
  2. Genesis 실행
    MO2 오른쪽 위 실행 목록에서 Star Wars Genesis를 선택하고 실행합니다. 첫 실행은 몇 분 걸릴 수 있습니다. MO2가 잠겼다는 이유로 Unlock을 누르지 않습니다. 메인 메뉴에서 아무것도 클릭되지 않으면 메인 메뉴 입력 불가를 확인하세요.
  3. 새 게임 시작
    메인 메뉴에서 새 게임을 시작하고 완전히 로딩될 때까지 기다립니다. 광산/동굴 같은 잘못된 위치에 스폰되면 공식 Wrong Spawn 안내를 확인합니다.
  4. 수동 저장 후 게임 재시작
    캐릭터 생성 뒤 수동 저장하고 게임을 완전히 종료했다가 다시 실행해 방금 만든 저장을 불러옵니다. 저장 버튼이 비활성화돼 있다면 원문은 인벤토리를 열었다 닫아보라고 안내합니다.
  5. 설정 확인
    그래픽 설정은 자동 구성됩니다. 임의 변경은 가능하지만 V-Sync, Dynamic Resolution, Dialogue Camera, DLSS, Frame Generation 같은 항목은 불안정성에 영향을 줄 수 있어 공식 권장 설정을 먼저 확인하세요.
Windows 11 Auto HDR: 원문은 조명 품질을 위해 Auto HDR을 끄라고 안내합니다. HDR 자체를 반드시 끄라는 뜻은 아닙니다.

난이도

Genesis는 비레벨 스케일링 월드를 사용하며 기본 난이도는 Normal입니다. 난이도 변경은 MO2 왼쪽의 난이도 옵션으로 하며 한 번에 하나만 활성화합니다.

Immersive는 몇 발만 맞아도 사망할 수 있는 매우 높은 난이도로 안내됩니다.

선택 사항: HD Overhaul

고해상도 텍스처는 100GB 이상의 추가 용량과 높은 VRAM을 요구할 수 있습니다. 설치하려면 HD Overhaul 한국어 안내를 먼저 확인하세요.
