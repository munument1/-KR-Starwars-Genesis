Linux 설치 안내

원문 확인: 2026-10-07 · 공식 원문 ↗

Genesis 제작자는 Linux를 직접 사용하지 않는다고 밝히며 커뮤니티에서 작성한 별도 설치 가이드를 소개합니다.

권장 진행 방식

  1. 공식 Linux Support 페이지에서 Universal Distro Guide 또는 Bazzite Guide를 선택합니다.
  2. 소개된 커뮤니티 도구와 최신 Wabbajack 파일의 지원 상태를 확인합니다.
  3. Windows용 설명과 공통되는 설치 단계는 따르되, 문서 설정은 Manual Document Installation 절차를 사용합니다.
  4. Windows PowerShell 설정 스크립트는 Linux에서 그대로 실행되지 않으므로 원문의 수동 설정 및 기본값 안내를 사용합니다.

자주 발생하는 증상

게임이 Starfield 원본 상태로 실행되거나 NPC의 신체가 보이지 않으면 StarfieldCustom.ini가 정확한 문서 경로에서 로드되는지 확인해야 합니다. 원문은 수동 문서 설치 오류를 가장 먼저 점검하도록 안내합니다.

Linux 문제는 원본 사이트에서 안내하는 Discord의 Linux-Help 채널과 커뮤니티 가이드를 참조하는 것이 좋습니다.
