오디오/FPS 끊김

공식 가이드는 Starfield와 Star Wars Genesis를 모두 내장 NVMe SSD에 설치하라고 강조합니다. SATA SSD·외장 SSD·HDD 환경에서는 오디오 끊김, 프레임 스터터, 매우 긴 로딩이 발생할 수 있습니다.

새 게임·도시 진입에서 크래시

백신, Windows 권한, 오래된 모드 잔재를 먼저 배제합니다. 문제가 계속된다면 RAM·SSD·GPU 드라이버·온도 같은 PC 자체 안정성도 확인합니다.

  • RAM: 다른 앱도 자주 종료된다면 메모리 안정성 점검.
  • SSD: SMART 상태와 읽기/쓰기 성능 확인.
  • GPU 드라이버: 다른 게임에서도 이상이 있다면 재설치 고려.
  • 온도: CPU/GPU 과열 여부 확인.
블루스크린·PC 강제 종료: 정상적인 게임 크래시와는 다른 증상입니다. 원문은 이 경우 하드웨어·전원·드라이버 안정성 문제를 우선 점검하라고 안내합니다.
