MENU LAG

메뉴 렉 해결

원문 확인: 2026-10-07 · 공식 원문 ↗

일반 플레이에서는 정상 FPS가 나오다가 Esc 일시정지 메뉴를 연 뒤 FPS가 약 10 수준으로 떨어지고 계속 유지되는 현상을 다룹니다.

2026년 8월 이후 변경: Genesis 제작진은 Nexus의 Menu Lag Fix 제작을 지원했고, 공식 가이드는 이 수정이 8~12GB VRAM 사용자 대부분에게 효과가 있다고 설명합니다. 계속 발생한다면 재현 로그를 제공해 달라고 요청하고 있습니다.

즉시 복구용 임시 방법

  • Esc를 몇 번 반복해서 누릅니다.
  • 빠른 저장을 시도합니다.
  • 가능하면 Esc 일시정지 대신 Tab 메뉴를 사용합니다.

계속 발생할 때

  1. 80GB page file
    Windows 페이지 파일을 최소 80000MB 수준으로 확보합니다.
  2. VRAM에 맞는 해상도
    VRAM이 12GB 이하라면 1440p보다 높은 해상도와 HD Overhaul을 피합니다.
  3. 충돌 프로그램 종료
    충돌 프로그램 목록을 확인합니다.
  4. 자동 저장 끄기
    Gameplay Options 하단의 자동 저장을 비활성화합니다. 대신 빠른 저장/수동 저장을 습관화해야 합니다.
  5. 셰이더 재컴파일
    MO2 오른쪽 위 실행 항목을 SFSE에서 StarfieldShaderReset으로 바꾸고 한 번 실행합니다.

추가로 시험할 설정

NVIDIA 제어판에서 Starfield 프로필의 Power Management Mode를 Prefer maximum performance로 바꿔 볼 수 있습니다.

Starfield.exe → 속성 → 호환성에서 전체 화면 최적화 사용 중지를 시험할 수 있으며, 원문은 Change settings for all users에서 관리자 권한 실행도 추가 후보로 제시합니다.

Steam Offline Mode가 해결했다는 사용자 사례도 원문에 있지만 실험적 방법으로 표시되어 있습니다.

수정 모드 로그 제공

Menu Lag Fix를 사용하는데도 반복되면 메뉴 렉을 재현하고 5~10초 기다린 뒤 Documents\My Games\Starfield\SFSE\Logs\StarfieldPauseLODHold.log를 Genesis 지원 채널에 제공하는 것이 원문 권장 절차입니다.

메뉴 렉은 저VRAM 환경에서 두드러지는 Starfield 엔진/메모리 관리 문제로 설명됩니다. 무조건 Genesis 파일이 손상됐다고 가정하지 마세요.
