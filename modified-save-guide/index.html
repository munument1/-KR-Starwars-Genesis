MODIFIED SAVE

Modified Save 관리

원문 확인: 2026-10-07 · 공식 원문 ↗

추가 모드는 장기적인 약속입니다. 한 번 추가 모드를 사용한 세이브는 나중에 모드를 제거해도 순정 Genesis 세이브로 돌아가는 것이 아닙니다.

Genesis 업데이트 시 Wabbajack은 원래 목록에 없는 추가 모드를 삭제할 수 있습니다. 유지하려면 MO2의 모드 이름 앞에 [NoDelete] 를 붙여야 하지만, 이것은 단순히 삭제를 막을 뿐 새 Genesis 버전과의 호환성을 보장하지 않습니다.

지원 채널 구분

Modified Save 사용자는 게임 내 문제를 일반 Help/Bug Report 채널보다 Modified-Install 채널에서 다루는 것이 원칙입니다.

일반 지원으로도 볼 수 있는 사례

  • Wabbajack/Mod Organizer 2 설치 자체의 문제.
  • 추가한 모드가 독립 방어구뿐인데 지역 환경이 깨진 경우.
  • 추가한 모드와 명백히 무관한 NPC/음성 문제.

Modified Install 문제로 보는 사례

  • 새로 넣은 방어구 자체가 깨짐.
  • 수십 개 게임플레이 모드 추가 후 크래시.
  • 대량의 함선 모드 추가 후 함선/상점 문제가 발생.
  • NPC overhaul을 추가한 뒤 Genesis NPC가 원래 Starfield 외형으로 돌아감.
업데이트 전 세이브 백업, 추가 모드 목록 기록, 각 모드의 업데이트 호환성 확인을 권장합니다.
