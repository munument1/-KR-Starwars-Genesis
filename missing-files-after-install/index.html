설치 후 파일 누락

원문 확인: 2026-10-07 · 공식 원문 ↗

설치가 끝났는데 ModOrganizer.exe, GENESIS_DOCUMENTS.bat 같은 파일이 빠져 있는 경우입니다.

Wabbajack으로 복구

  1. Star Wars Genesis\Wabbajack\Wabbajack.exe를 실행합니다.
  2. Browse Lists → Install from Disk로 들어갑니다.
  3. 처음 설치할 때 사용한 경로를 똑같이 지정합니다.
  4. 다시 설치를 시작하면 이미 정상인 파일은 재다운로드하지 않고 누락된 항목만 복구합니다.
복구 후에도 계속 같은 파일이 사라진다면 백신 또는 Windows 보안이 격리하는지 확인하세요.
