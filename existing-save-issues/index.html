EXISTING SAVE ISSUES

기존 세이브 업데이트 주의

원문 확인: 2026-10-07 · 공식 원문 ↗

7.0 이하 세이브: 원문은 새 세이브가 필요하다고 명시합니다. 8.0 이후 세이브는 비교적 안전하지만 업데이트마다 작은 문제가 누적될 수 있습니다.

Genesis는 현재 기존 세이브 친화적인 방향을 유지하고 있지만, 여러 버전을 한꺼번에 건너뛸수록 시각·NPC·장비·퀘스트 상태 문제가 늘어날 수 있습니다.

최근 버전에서 특히 볼 것

8.8.3

  • 이미 광선검을 가지고 있다면 Imperial 도시의 광선검 감지 기능을 위해 기존 것을 버리고 새로 획득해야 할 수 있습니다.
  • 광선검 ID 확인: help "lightsabers" 4 weap
  • 깨진 NPC가 보이면 원문은 numpad 1의 Existing Save Cleaner 사용을 안내합니다.
numpad 1의 Existing Save Cleaner로 해결되지 않는 NPC는 깨진 NPC 수동 복구를 사용하세요.

8.8.2

  • Dantooine 등의 Rebel Technician 의상 누락.
  • Nar Shaddaa 일부 상인의 머리 누락.
  • Geriss Minor의 Imperial Military Base 마커가 이전 위치에 남을 수 있음.

8.8.15

과거 콘솔로 체력을 올린 사용자는 새 기본 난이도에서 지나치게 강해질 수 있습니다. 원문은 필요시 player.modav health -x 형식으로 추가했던 체력을 줄이는 방법을 안내합니다.

8.7

  • 포스 능력 획득 순서 변경은 기존 세이브에 완전히 소급되지 않을 수 있습니다.
  • 기존 제트팩은 새 이동 값이 반영되지 않아 버리고 새로 획득해야 할 수 있습니다.
  • 일부 NPC 외형/의상은 기존 세이브에서 갱신되지 않을 수 있습니다.
  • 기존 인벤토리의 일부 샷건/장비 수치가 새 버전과 다를 수 있습니다.
이 페이지는 최신·중요 항목 위주의 한국어 요약입니다. 오래된 세이브를 여러 버전 건너뛰어 업데이트한다면 반드시 공식 Existing Save Issues 전체 기록을 확인하세요.

기존 세이브의 버전별 추가 문제

  • 8.8.1: Coruscant와 Gallofree의 일부 의상 갱신되지 않은 NPC는 Smuggler, Banking Clan Representative, Black Sun Operative 포함
  • 8.6: 업데이트 전에 메인 스토리를 완료했다면 숨겨진 Force Sensitive 퍽이 소급되지 않습니다. help "force sensitive"의 가장 큰 퍽 ID를 player.addperk <id>에 사용하거나, slm 14에서 포스 감응 배경을 선택합니다.
  • 8.6: Tython 포스 트레이너는 기존 세이브에서 보스로 등장하지 않음
  • 8.5: 타이손 트레이너로 인해 포스 에센스가 음수가 됐다면 player.setav quantumessence 5, player.modav quantumessence 5, player.forceav quantumessence 5를 하나씩 시도합니다. 양수로 바뀌면 중단하고 트레이너에게 능력을 배웁니다. 원문은 확정된 복구법이 아닌 시도로 안내합니다.
  • 8.5: 유물 전달을 안내하는 메인 프롤로그가 퀘스트 로그에 다시 나타나면 완료합니다.
  • 8.6: 기존 인벤토리의 방어구에는 새 전설 퍽이 반영되지 않으므로 같은 방어구를 새로 획득해야 합니다.
  • 8.6: UC 퀘스트라인을 이미 완료했다면 새 퀘스트라인을 경험할 수 없습니다. 진행 중인 비활성화 바닐라 퀘스트는 수행하지 않도록 안내합니다.

8.2~8.4 업데이트 주요 누락

  • 8.4: 프론티어를 대체하는 Echelon 스타터십은 수정 시 크래시 및 프론티어로 원복 위험이 있어 사용 권장 안 함
  • 8.4: Nas Choka와 Nom Anor를 이미 만났다면 인간 머리가 외계인 머리를 뚫고 나오는 영구적 비주얼 버그 발생
  • 8.3: 제국 신병으로 섀도우 콜렉티브 도입부를 진행 중이었다면 완료할 수 없으므로, 원문은 범죄 경로로 다시 시작하도록 안내합니다.
  • 8.2: 이전에 방문한 Coruscant, Dantooine, Nar Shaddaa 선박 상인은 새 함선을 판매하지 않음
