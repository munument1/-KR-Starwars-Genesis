EXISTING SAVE ISSUES

기존 세이브 업데이트 주의

원문 확인: 2026-10-07 · 공식 원문 ↗

7.0 이하 세이브: 원문은 새 세이브가 필요하다고 명시합니다. 8.0 이후 세이브는 비교적 안전하지만 업데이트마다 작은 문제가 누적될 수 있습니다.

Genesis는 현재 기존 세이브 친화적인 방향을 유지하고 있지만, 여러 버전을 한꺼번에 건너뛸수록 시각·NPC·장비·퀘스트 상태 문제가 늘어날 수 있습니다.

최근 버전에서 특히 볼 것

8.8.3

  • 이미 광선검을 가지고 있다면 Imperial 도시의 광선검 감지 기능을 위해 기존 것을 버리고 새로 획득해야 할 수 있습니다.
  • 광선검 ID 확인: help "lightsabers" 4 weap
  • 깨진 NPC가 보이면 원문은 numpad 1의 Existing Save Cleaner 사용을 안내합니다.

8.8.2

  • Dantooine 등의 Rebel Technician 의상 누락.
  • Nar Shaddaa 일부 상인의 머리 누락.
  • Geriss Minor의 Imperial Military Base 마커가 이전 위치에 남을 수 있음.

8.8.15

과거 콘솔로 체력을 올린 사용자는 새 기본 난이도에서 지나치게 강해질 수 있습니다. 원문은 필요시 player.modav health -x 형식으로 추가했던 체력을 줄이는 방법을 안내합니다.

8.7

  • 포스 능력 획득 순서 변경은 기존 세이브에 완전히 소급되지 않을 수 있습니다.
  • 기존 제트팩은 새 이동 값이 반영되지 않아 버리고 새로 획득해야 할 수 있습니다.
  • 일부 NPC 외형/의상은 기존 세이브에서 갱신되지 않을 수 있습니다.
  • 기존 인벤토리의 일부 샷건/장비 수치가 새 버전과 다를 수 있습니다.
이 페이지는 최신·중요 항목 위주의 한국어 요약입니다. 오래된 세이브를 여러 버전 건너뛰어 업데이트한다면 반드시 공식 Existing Save Issues 전체 기록을 확인하세요.
