기존 Genesis 업데이트

원문 확인일 2026-10-07 · 공식 Updating Guide ↗

대상: 이 페이지는 이미 Genesis를 설치한 사용자용입니다. 처음 설치한다면 신규 설치 가이드를 사용하세요.

원문 기준 버전

  • Latest Supported Starfield: 1.16.244
  • Current Starfield: 1.16.244
  • Latest Genesis: 8.8.3

공식 패치노트 메뉴에는 8.8.31 항목도 존재하므로, 실제 업데이트 직전에는 Updating 페이지의 버전 표시와 패치노트를 함께 확인하세요.

필수 조건

  • Shattered Space
  • 새 세이브 또는 수정하지 않은 Genesis 세이브
  • Wabbajack
  • 최소 80GB의 Windows page file

업데이트 전에 반드시 확인

원본은 아래 네 사용자 유형을 각각 아이콘으로 구분합니다.

기존 세이브 사용자세이브 손상을 막기 위한 전용 안내를 먼저 확인.
Genesis에 모드를 추가한 사용자추가 모드 보존 절차를 먼저 적용.
8.2 이전 설치 사용자신형 설치기 도입 전 버전은 마이그레이션 절차 필요.
HD Overhaul 사용자업데이트 중 HD 텍스처가 삭제되지 않도록 보호 절차 적용.

업데이트 절차

  1. 도시와 함선을 벗어나 수동 저장
    기존 세이브를 계속 쓸 경우 임의의 달 표면으로 이동해 함선 밖에서 수동 저장합니다. 업데이트 후에는 그 저장을 불러옵니다. 8.7.0 이하에서 올라오는 경우 원문은 Starfield 게임 폴더의 vcruntime140_1.dll이 있으면 삭제하도록 안내합니다.
  2. 게임과 MO2를 완전히 종료
    Starfield 업데이트가 필요한 경우 지원 버전에 맞춘 뒤 진행합니다.
  3. 최신 Genesis 설치기 실행
    공식 Updating 페이지에서 StarWarsGenesisSetup.exe를 Standard Download로 받습니다.
  4. 기존 Genesis 설치 위치 지정
    처음 설치할 때 사용한 드라이브 루트의 Star Wars Genesis 위치를 그대로 선택합니다.
  5. Wabbajack 경로 확인
    Installation Location은 반드시 Star Wars Genesis\Game이어야 합니다. 상위 Star Wars Genesis 폴더만 지정하면 Wabbajack compiler와 같은 위치에 설치할 수 없다는 오류가 날 수 있습니다.
  6. 업데이트 설치 시작
    Nexus 로그인 요청이 나오면 로그인합니다. 파일 삭제 확인 팝업이 나오면 원문은 Continue를 선택하도록 안내합니다. 다운로드 오류가 반복되면 Wabbajack 오류 안내를 확인하세요.
  7. GENESIS_DOCUMENTS.bat 실행
    업데이트가 끝난 뒤 Star Wars Genesis\Game\GENESIS_DOCUMENTS.bat를 다시 실행하고 질문에 Y/N으로 답합니다.
  8. MO2 실행 후 이전 저장 불러오기
    ModOrganizer.exe를 실행하고 Genesis를 시작한 뒤 업데이트 전에 안전한 장소에서 만든 수동 저장을 불러옵니다.

사용자 유형별 주의

기존 세이브

업데이트 전 도시·함선 내부를 피하고 별도 수동 저장을 만든 뒤, 업데이트 완료 후 그 저장에서 이어가는 것이 핵심입니다. 버전별로 세이브 호환 조건이 바뀔 수 있으므로 원문의 Existing Save 전용 안내를 반드시 함께 확인하세요.

개인 모드를 추가한 Genesis

Wabbajack 업데이트는 원본 모드리스트 상태로 되돌리는 과정에서 사용자 추가 파일을 지울 수 있습니다. 개인 모드를 사용한다면 공식 Modified Genesis 안내에 따라 보존 표시와 백업을 먼저 처리하세요.

8.2 이전 구형 설치

현재 설치기 구조가 도입되기 전 버전에서 올라온다면 단순 덮어쓰기보다 마이그레이션 안내를 먼저 따라야 합니다.

HD Overhaul

Wabbajack 업데이트 중 고해상도 텍스처가 삭제되지 않도록 HD Overhaul 안내의 업데이트 보호 절차를 확인합니다.

이미지 처리: 설치 가이드와 마찬가지로 원본 사이트가 호스팅하는 이미지를 직접 참조하며 저장소에 복제하지 않습니다.
