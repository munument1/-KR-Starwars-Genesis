이 페이지는 기존 Genesis 설치 사용자용입니다. 처음 설치하는 경우 신규 설치 가이드를 사용하세요.

원문에서 현재 표시하는 버전

  • 지원 Starfield: 1.16.244
  • 현재 Starfield: 1.16.244
  • Genesis: 8.8.3

원본 사이트의 패치노트에는 8.8.31 항목도 표시되어 있어 페이지별 버전 표기가 일치하지 않을 수 있습니다. 업데이트 실행 전에는 반드시 공식 Updating 페이지의 최신 숫자를 다시 확인하세요.

업데이트 전 체크

  • 기존 세이브를 계속 사용할 경우 공식 Existing Save 안내를 확인
  • Genesis에 개인 모드를 추가했다면 Modified Genesis 안내를 확인
  • 구형 설치 구조(Pre-8.2)를 사용했다면 마이그레이션 안내 확인
  • HD Overhaul을 사용 중이면 업데이트 때 텍스처가 삭제되지 않도록 별도 보호 절차 확인

기본 흐름

  1. 안전한 장소에서 수동 저장
    기존 세이브 사용자는 도시나 우주선 내부를 피하고 공식 가이드가 권장하는 방식으로 저장합니다.
  2. 게임과 MO2 종료
    필요한 경우 Starfield를 지원 버전으로 맞춥니다.
  3. 최신 Genesis 설치기 실행
    공식 Updating 페이지의 다운로드 링크를 사용합니다.
  4. 기존 Genesis 설치 위치 선택
    처음 설치했던 동일한 위치를 사용합니다.
  5. Wabbajack 업데이트 진행
    기존 설치와 새 버전의 차이를 적용합니다.
세이브 호환성은 Genesis 업데이트에서 특히 중요합니다. 버전별 예외 조건은 요약하지 않고 다음 단계에서 원문 구조대로 세부 번역할 예정입니다.
