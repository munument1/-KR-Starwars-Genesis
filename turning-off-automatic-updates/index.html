Steam 자동 업데이트 끄기

원문 확인: 2026-10-07 · 공식 원문 ↗

  1. Steam 라이브러리에서 Starfield를 찾습니다.
  2. 우클릭 → Properties.
  3. Automatic Updates에서 Only update this game when I launch it에 해당하는 옵션으로 설정합니다.

Genesis는 Mod Organizer 2에서 실행하므로 Steam에서 직접 게임을 실행한 것으로 처리되지 않아 이 설정을 유지하면 자동 업데이트를 피할 수 있다는 것이 원문의 설명입니다.

Starfield 업데이트가 배포된 뒤에는 Steam에서 직접 실행하거나 파일 무결성 검사를 하지 마세요. 둘 다 게임 파일을 최신 버전으로 올려 Genesis가 지원하는 버전에서 벗어날 수 있습니다.
