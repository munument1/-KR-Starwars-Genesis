EXISTING SAVE · NPC RESET

깨진 NPC 복구

원문 확인: 2026-10-07 · 공식 원문 ↗

기존 세이브를 새 Genesis 버전으로 올린 뒤 NPC의 종족·머리·의상 등이 잘못 보이거나, 추가 모드 때문에 NPC 레코드가 꼬인 경우에 사용하는 수동 초기화 절차입니다.

먼저 수동 저장을 새 슬롯에 만드세요. 콘솔에서 다른 오브젝트를 선택한 상태로 명령을 실행하면 엉뚱한 대상을 건드릴 수 있습니다.
  1. 문제가 있는 NPC 바로 앞에서 콘솔(~ 또는 키보드 설정에 따른 콘솔 키)을 엽니다.
  2. NPC를 클릭하고 화면 중앙 선택 정보에 NPC가 표시되는지 확인합니다.
  3. disable을 입력합니다.
  4. 콘솔을 닫았을 때 NPC가 사라졌는지 확인합니다. 사라지지 않았다면 잘못 선택한 것이므로 저장을 다시 불러와 처음부터 진행합니다.
  5. 같은 대상을 유지한 상태로 콘솔을 다시 열어 enable, 이어서 resetinventory를 입력합니다.
  6. NPC가 새 외형·의상으로 정상화됐는지 확인합니다.

그래도 안 될 때

원문은 다음 명령을 순서대로 추가 시험하도록 안내합니다.

resetinventory
recycleactor
disable
enable
