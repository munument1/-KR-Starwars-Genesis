8.8.3 패치노트

원문 확인: 2026-10-07 · 공식 원문 ↗

퀘스트·동료 대화, 블래스터 FX, 환경 자산, Outpost Raid, Jedi Hunter, 광선검 적발/제국 현상금, 함선 전투, Force Power, 설치기까지 크게 손본 대형 업데이트입니다.

퀘스트 / 동료

  • Act 2 이후 동료 4명의 대화와 Rebel/Imperial 퀘스트 결과 대화를 대폭 완성.
  • 동료 개인 질문과 배경 이야기 추가.
  • Rebel/Imperial 퀘스트 선택에 맞는 affinity 결과 적용.
  • Meeka 대화 추가·흐름 개선.

환경과 전투

  • 200개 이상의 내부/외부 소품 및 건물 교체.
  • 기존 airlock 다수를 에너지 실드로 교체해 진입 대기 시간 제거.
  • 블래스터 볼트와 충돌 FX 개선.
  • Nimble Ships 기반으로 함선 속도·부스트·회전·타깃 락을 전반 조정.

Outpost Raids

Scavenger/Trandoshan 습격이 발생할 수 있고 대응이 늦으면 자원의 25%가 도난됩니다. 제국 현상금과 소속 조건에 따라 Imperial Raid도 발생할 수 있습니다.

Jedi Hunters / 광선검 적발

  • Force Sensitive이며 Empire 소속이 아닌 플레이어는 최대 8명의 고유 Imperial Hunter에게 추적될 수 있음.
  • 제국 지역에서 비제국 플레이어가 광선검을 들고 NPC 시야 내 15m에 들어오면 25,000 credit bounty가 생길 수 있음.
  • 기존 세이브의 기존 광선검은 새 기능이 적용되지 않을 수 있어 새로 획득해야 함.

Force / 배경 / 함선 부품

  • Double Jump 스킬 추가.
  • Force Repulse WIP 추가.
  • Veteran, Clone Mercenary, Droid Sympathizer, Separatist Roots, Displaced 등 배경/특성 추가·조정.
  • 바닐라 함선 부품의 vendor/level 제한을 크게 완화.

Existing Save Cleaner

기존 세이브에서 머리 누락 등 깨진 NPC를 만났을 때 numpad 1로 주변 NPC를 정리하는 스크립트를 추가했습니다.

설치기 / 유지보수

  • 필요할 경우 .NET Desktop Runtime / ASP.NET Core Runtime 8.0.24 자동 설치.
  • Menu Lag Fix 업데이트.
  • 여러 플러그인 통합 및 마스터 의존성 정리.
8.8.3은 변경 항목이 매우 많습니다. 퀘스트 비활성화 목록과 세부 버그 수정은 공식 전체 패치노트에서 확인하세요.

추가된 함선 및 장비 변경

  • VikoizBeast의 YTS-27 Corsair 함선이 지오노시스(Geonosis) 상점에 추가되었습니다.
  • 크림슨 플릿 퀘스트라인 비활성화로 인해 상점에서 스캔 재머(Scan Jammers)를 고가에 구매할 수 있습니다.
  • SETI 함선 외부 조명 최적화 모드가 통합되어 조명이 추가되었습니다.

아웃포스트 레이드 및 제국 현상금 규칙

  • 스캐빈저/트란도샨의 아웃포스트 습격은 매일 40% 확률로 발생하며 7일 쿨타임을 가집니다.
  • 제국 레이드는 제국 현상금이 있고 제국 소속이 아닌(탈영병 포함) 조건에서 궤도전과 지상전 단계로 발생합니다.
  • 현상금 수배 시 스톰트로퍼를 매수하는 옵션이 제거되었으며 전투 또는 항복(XP 페널티 및 7일 경과)만 가능합니다.

세이브 호환성 및 퀘스트 비활성화

  • 기존 세이브 충돌 방지 및 향후 업데이트 호환을 위해 나르 샤다, 코러산트, 단투인, 지오노시스 등의 수많은 바닐라/서브 퀘스트 진입이 비활성화되었습니다.
  • 버그로 인해 비정상 상태가 된 NPC는 숫자패드 1을 눌러 수정할 수 있습니다.
