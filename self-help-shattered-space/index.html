Shattered Space 확인

원문 확인: 2026-10-07 · 공식 원문 ↗

Genesis가 실행 직후 크래시한다면 가장 먼저 유료 Shattered Space DLC가 실제로 설치되어 있는지 확인합니다.

원본 Self Help는 이것을 실행 크래시의 가장 흔한 원인으로 꼽습니다. DLC가 빠져 있으면 Mod Organizer 2의 Plugins 탭에서 여러 항목에 빨간 느낌표가 나타날 수 있습니다.

확인 방법

  1. Steam → Starfield → Properties → DLC에서 Shattered Space 소유 및 설치 여부를 확인합니다.
  2. 설치가 빠져 있다면 다운로드를 완료합니다.
  3. Mod Organizer 2를 완전히 종료했다가 다시 실행합니다.
  4. Plugins 탭의 빨간 느낌표가 사라졌는지 확인합니다. 원문은 맨 아래 하나의 경고는 정상일 수 있다고 설명합니다.
DLC가 설치되어 있는데도 계속 크래시? 실행 즉시 크래시 페이지에서 백신·충돌 앱·바닐라 Starfield 실행 여부를 확인하세요.
