진영 대체 관계

  • Genesis는 V3 이후 바닐라 세계관을 기준으로 삼지 않으며, 퀘스트와 진영 관계를 재작성했습니다. 아래 대응은 기존 데이터의 대체 관계입니다.
  • UC → 제국, Freestar Collective → 반란 연합, Crimson Fleet → 섀도우 콜렉티브, Spacers → 스캐빈저/레이더, Ecliptic → 트란도샨.
  • Va’ruun → 시스 제국, Starborn → 유우잔 봉, SysDef → ISB, Disciples → 파이크 신디케이트, Seokguh Syndicate → 허트 카르텔.
  • Strikers → 크림슨 던, Tracker’s Alliance → 현상금 사냥꾼 길드, Shaw Gang → 스우프 갱, Scow/Collector → 오나카 갱.
  • 터스켄 레이더와 자와는 타투인의 독립 진영입니다. 크림슨 던은 나르 샤다, 현상금 사냥꾼 길드는 단투인에서 찾습니다. 원문 목록은 개발 중이며 향후 진영이 추가될 수 있습니다.
