HD Overhaul 설치

원문 확인일 2026-10-07 · 공식 원문 ↗

공식 사이트가 추천하는 HD Overhaul은 100GB가 넘는 고해상도 텍스처 구성을 사용하며, GPU VRAM 요구량이 큽니다.

공식 VRAM 가이드

  • 1080p: 10GB
  • 1440p: 12GB
  • Ultrawide: 16GB
  • 4K: 24GB 이상

설치 흐름

  1. Nexus의 HD Overhaul 파일을 수동 다운로드
    공식 페이지가 지정한 파트만 받습니다.
  2. 압축을 풀지 않고 Downloads 폴더로 이동
    Star Wars Genesis\Game\Downloads에 보관합니다.
  3. MO2에서 각 파트를 설치
    Part 1, Part 2처럼 식별하기 쉽게 이름을 붙입니다.
  4. Starfield HD Overhaul.esm 설치
    원문의 MO2/Nexus 연결 절차를 따릅니다.
  5. Overwrite 확인
    공식 가이드가 지시하는 시점에 Overwrite 내부를 정리합니다.
업데이트 보호: Genesis 업데이트 때 HD 텍스처가 지워지지 않도록 원문은 각 관련 모드 이름 앞에 [NoDelete]를 붙이는 방법을 안내합니다. 공백까지 정확히 유지하세요.
