HD Overhaul 설치

원문 확인: 2026-10-07 · 공식 원문 ↗

Genesis 제작자가 권장하는 Starfield HD Overhaul은 은하 전역의 수천 개 텍스처와 NPC의 Hair, Beard, Skin, Eyes, Eyelashes 등을 고해상도로 교체합니다. 전체 용량은 100GB를 조금 넘습니다.

권장 VRAM

  • 1080p: 10GB
  • 1440p: 12GB
  • Ultrawide: 16GB
  • 4K: 24GB 이상
VRAM이 12GB 이하라면 공식 Menu Lag 가이드는 1440p를 넘는 해상도와 HD Overhaul을 피하라고 안내합니다.

설치 절차

  1. Part 1~18을 수동 다운로드
    공식 Nexus 페이지에서 Manual Download로 Part 1~18만 받습니다. 다른 추가 파트, 패치, ESM, INI는 이 단계에서 무시합니다.
  2. 압축을 풀지 않고 Downloads 폴더로 이동
    받은 압축파일을 그대로 Star Wars Genesis\Game\Downloads에 넣습니다. MO2 오른쪽 Downloads 탭에 표시되어야 합니다.
  3. 각 파트 설치
    각 파일을 우클릭해 Install을 선택하고 Part 1, Part 2처럼 알아보기 쉽게 이름을 붙입니다. 설치가 끝나면 MO2 왼쪽 목록 하단에 파트들이 활성화되어 보여야 합니다.
  4. Starfield HD Overhaul.esm 설치
    같은 Nexus 페이지에서 Starfield HD Overhaul.esm은 Mod Manager Download로 설치합니다. 카테고리를 찾지 못했다는 팝업은 Disable을 누르고, 모드 이름을 Starfield HD Overhaul로 정리한 뒤 체크합니다.
  5. Overwrite 비우기
    MO2 왼쪽 목록 맨 아래의 빨간 Overwrite를 더블클릭하고 내부 파일을 모두 삭제합니다. 이미 비어 있다면 건너뜁니다.
  6. 실행 테스트
    이제 Genesis를 실행합니다. 실행 문제가 생기면 Self Help를 확인합니다.

Genesis 업데이트에서 보호

Wabbajack 업데이트 때 HD Overhaul 파트가 삭제되지 않게 하려면 각 모드 이름 앞에 [NoDelete] 를 붙입니다. 공백까지 정확히 유지하세요.

  • [NoDelete] Starfield HD Overhaul part 01
  • [NoDelete] Starfield HD Overhaul part 02
  • 나머지 파트와 ESM도 같은 방식
원본 스크린샷은 저장소에 복제하지 않고 Genesis 공식 사이트의 이미지 URL을 직접 참조합니다.
