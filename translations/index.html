Genesis 번역 관련 안내

원문 확인일 2026-10-07 · 공식 Translations ↗ · 공식 FAQ ↗

게임 본편 번역과 사이트 가이드 번역은 별개입니다. 오래된 Genesis용 게임 번역 모드는 세이브 손상을 일으킬 수 있다고 공식 사이트가 강하게 경고합니다.

공식 사이트의 현재 상태

Translations 페이지는 8.8.31 기준으로 프랑스어와 독일어를 Working, 헝가리어를 WIP로 표시하며 기타 언어는 지원하지 않는 것으로 표시합니다.

커뮤니티 번역 정책

공식 FAQ는 현재 지원 언어가 영어라고 설명하면서도 커뮤니티 번역 자체는 환영한다고 밝히고 있습니다. 단, Genesis가 업데이트되면 오래된 번역을 내려두거나 새 버전에 맞게 함께 업데이트하여 사용자가 구버전 콘텐츠로 플레이하지 않게 해야 한다는 조건을 명확히 둡니다.

이 저장소의 대응: 각 페이지에 원문 확인일을 남기고, 검색엔진 색인을 막으며, 원본과 버전이 달라진 것이 확인되면 해당 페이지에 구버전 경고를 표시하는 방향으로 관리합니다.

한국어 게임 번역을 별도로 진행할 경우

사이트 번역과 달리 실제 게임 문자열 번역은 Genesis 버전과 강하게 결합되어 있으므로, 대응 버전을 명시하고 업데이트마다 변경된 플러그인·문자열을 다시 검증하는 별도 배포 체계가 필요합니다.
