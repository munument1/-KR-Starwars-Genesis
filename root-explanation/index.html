  • 드라이브 루트는 최상위 위치입니다. Steam 게임 경로가 K:\SteamLibrary\steamapps\common\Starfield라면 루트는 K:\입니다.
  • Genesis 설치 위치는 K:\Star Wars Genesis처럼 루트 바로 아래에 둡니다. K:\Games나 Program Files, Starfield 게임 폴더 안에 넣지 않습니다.
  • 설치 후 폴더를 이동하거나 이름을 바꾸지 마세요.
