구형 설치 마이그레이션

원문 확인: 2026-10-07 · 공식 원문 ↗

공식 현재 권장: 8.1 이전의 오래된 Genesis 설치라면 마이그레이션보다 기존 Genesis 폴더를 삭제하고 새 설치를 하는 편을 권장합니다. 2026년 이후 200개 이상의 모드가 갱신되었고 설치 방식도 달라졌기 때문입니다.

아래는 원문에 남아 있는 보관용 마이그레이션 절차입니다. 제작자는 이 방법을 선택해 문제가 생긴 경우 새 설치를 권할 것이라고 명시합니다.

  1. Mod Organizer 2를 종료합니다.
  2. 기존 Compiler와 Wabbajack 폴더를 삭제합니다.
  3. ModOrganizer.exe가 들어 있는 기존 Genesis 폴더를 Game으로 이름 변경합니다.
  4. 최신 StarWarsGenesisSetup.exe를 실행해 드라이브 루트에 새 Star Wars Genesis 구조를 만듭니다.
  5. 자동으로 열린 Wabbajack을 최소화하고, 앞서 이름 바꾼 Game 폴더를 새 Star Wars Genesis 폴더 안으로 이동합니다.
  6. 이후 일반 업데이트 가이드로 돌아가 나머지 절차를 진행합니다.
이 과정은 세이브와 [NoDelete]로 표시한 추가 모드를 건드리지 않는다고 원문은 설명하지만, 현재 권장 경로는 여전히 새 설치입니다.
