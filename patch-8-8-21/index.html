8.8.21 패치노트

원문 확인: 2026-10-07 · 공식 원문 ↗

대화·캐릭터 생성·메뉴·BAT/Documents 설정 안정성과 여러 버그를 정리한 업데이트입니다.

Main Story

  • Jodo Kast 대화 일부 재작성.
  • Main Quest Act 2의 일관되지 않은 선택지 수정.

Character Creation / Surgery

  • Surgery Clinic에서 외계 종족 변경 가능.
  • Trait 아이콘을 Star Wars 스타일로 변경.
  • 수술 관련 일부 UI 텍스트에 Aurebesh 적용.

메뉴

  • Freelanes의 Database 메뉴 지원.
  • Pause Menu의 Quit to Main Menu 제거.
  • Settings 가독성을 위한 vignette 추가.
  • Pause/Main Menu의 Quicksave·Crew 항목 제거.
  • Creations 버튼 제거 및 선택적 재활성화 모드 제공.

BAT / Documents

post-install BAT의 Documents 폴더 감지를 개선하고, StarfieldPrefs.ini 누락·문서 편집 차단·특수문자 경로 같은 오류를 사용자가 직접 확인할 수 있도록 검사 항목을 추가했습니다.

버그 수정

메인 메뉴의 바닐라 음악 중복, Gamorrean 머리/몸 문제, Nar Shaddaa Warehouse 무한 로딩 등 여러 문제를 수정했습니다.
