Genesis와 충돌할 수 있는 프로그램

원문 확인: 2026-10-07 · 공식 원문 ↗

다음은 제작자가 충돌 사례를 소개한 소프트웨어와 장치 환경입니다. 모든 PC에서 반드시 오류가 난다는 의미는 아니며, 발생한 증상과 일치할 때 먼저 종료·점검할 항목입니다.

오버레이·후킹·주입

  • Discord Game Overlay — 끊김이나 성능 문제. Discord 앱 자체를 끌 필요는 없습니다.
  • NVIDIA Performance Overlay — 일시 멈춤이나 끊김.
  • RivaTuner Statistics Server (RTSS) — 게임 속도가 느려지는 현상.
  • WeMod 및 MO2 외부 모드 주입 도구 — 안정성과 세이브 호환성 위험.
  • Battle.net Launcher — 안티치트 관련 간섭 보고.

보안·오디오·시스템 프로그램

  • BitDefender, Kaspersky, McAfee, Norton, Total Ultimate Defense
  • Nahimic, Sonic Studio / Sonic Suite, 일부 SteelSeries 오디오 소프트웨어
  • AMD StoreMI
  • Intel Extreme Tuning Utility — 특히 불안정한 CPU 오버클럭 설정에 주의

주변기기 확인

키보드·마우스를 USB 허브에 연결한 상태에서 끊김이 있다면 본체에 직접 연결해 비교합니다.

권장 진단: 프로그램을 종료하거나 오버레이 기능만 꺼서 증상 변화를 확인하세요. 백신 제거, 보안 해제, 오버클럭 변경은 정확한 원인을 확인하기 전에는 권장하지 않습니다. 원문의 목록은 모든 충돌 앱을 망라한 것이 아닙니다.
