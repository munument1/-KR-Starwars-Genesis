MODDED STARFIELD CLEANUP

기존 Starfield 모드 흔적 정리

원문 확인: 2026-10-07 · 공식 원문 ↗

과거에 Vortex, Creation Store 또는 수동 모딩을 사용했다면 Starfield 재설치만으로는 잔여 파일이 남을 수 있습니다. 공식 가이드는 Genesis 설치 전에 아래처럼 깨끗하게 초기화하라고 안내합니다.

  1. Starfield 설치 위치(steamapps\common\Starfield)를 찾아 Starfield 폴더 전체를 삭제합니다.
  2. Documents\My Games\Starfield 안의 Data 폴더를 삭제합니다.
  3. Steam에서 Starfield를 제거합니다.
  4. Steam에서 다시 설치합니다.

게임 폴더 위치를 모르겠다면 Steam의 Starfield → Properties → Installed Files → Browse에서 확인할 수 있습니다.

세이브 파일과 스크린샷을 보관해야 한다면 삭제 전 별도로 백업하세요. 이 절차의 목적은 게임 폴더와 Documents/Data에 남은 모드 파일을 없애는 것입니다.
