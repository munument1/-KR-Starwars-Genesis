MO2 다운로드 연결과 설치

  • Tools → Settings → Nexus에서 Connect to Nexus를 누르고 Associate with Download with manager links로 다운로드 연결을 등록합니다.
  • MO2의 Downloads 탭은 실제 다운로드 폴더와 연결됩니다. 수동으로 받은 압축 파일도 해당 폴더에 넣으면 표시됩니다.
  • 다운로드 항목을 우클릭해 Install합니다. 카테고리 없음 팝업의 Disable은 카테고리 기능을 끄는 선택이며 모드를 끄는 뜻이 아닙니다.
  • 기존 모드를 실수로 덮어쓰지 않도록 고유한 설치 이름을 사용합니다. 설치 후 왼쪽 목록 아래에서 체크해 활성화합니다.
  • 추가 모드가 Genesis와 호환된다는 보장은 없으므로, 추가 모드 설치 안내도 함께 확인하세요.
